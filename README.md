# GoCachy

Red social desarrollada como proyecto de portafolio profesional.

## Stack

- React + TypeScript + Vite
- Go (Gin)
- Azure Cosmos DB
- Docker + Docker Compose
- Azure DevOps (CI/CD)
- JWT + bcrypt

## Funcionalidades

- Registro y login con autenticación JWT
- Perfiles de usuario
- Términos y condiciones (Ley 19.628)
- Animaciones personalizadas
- Diseño responsive

## Instalación

```bash
docker compose up --build
